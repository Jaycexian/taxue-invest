# 基金调研元提示词（带取数）

> 用途：调研**单只基金**（或某位经理名下的全部产品），产出可复核、可落盘的调研结论。
>
> 为什么是「元」提示词：**该问什么、口径怎么定，是固定的；具体数字不能靠模型回忆，必须现拉。**
> 这条提示词只固定三样东西 —— 取数清单、分析框架、结论与口径红线；判断留给分析者。
>
> 血统：框架部分合并自两条既有资产 —— 2026-02-14 的《基金深度研究分析提示词（通用版）》
> （六维：画像/业绩/风险/组合/经理/成本体验）与 2026-03-07 的《基金经理分析提示词（优化版）》
> （看人/看业绩/看风格/看平台/看时机 + 结论四选一 + 数据缺口规则）。两条的共同短板是
> **没有取数层**：数据全靠模型回忆，所以只能写「请使用最新数据」这种兜底话。此处补齐取数层。

---

## 一、取数清单（先拉数，再动嘴）

**铁律：结论里的每一个数字，都必须能追到一条命令的输出。** 拿不到就写「数据不足」，不许估。

| 需要什么 | 命令 | 产出 | 拿不到时 |
|---|---|---|---|
| 任职期业绩/回撤/基准对比/逐日收益 | `invest-cli tenure <代码> --manager <姓名> [--excel out.xlsx]` | 分年度收益率与最大回撤、任职以来累计与年化、基金 vs 基准指数逐日、官方字段校验 | 报「业绩口径不可得」，不降级为「大概」 |
| 档案与基础画像 | `invest-cli fund <代码>` | 净值/规模/费率/十大重仓/同类分位/风险指标 | 换 `invest-cli intent deep fund <代码>`（盈米诊断雷达） |
| 持仓与行业穿透 | `invest-cli fund <代码>`（重仓段）+ `westock` 板块/资金流 | 前十大、行业集中度、换手 | 标注报告期，缺一期属正常 |
| 同类横向对标 | `invest-cli intent screen <条件>` 或 `invest-cli screen <条件>` | 同风格 3 只以内候选 | 至少凑 2 只，否则写「横向对标样本不足」 |
| 经理背景与在管 | `invest-cli tenure --manager <姓名> --brief` | 在管清单（含任职日/规模） | 无 |
| 舆情/经理观点 | `invest-cli info <关键词>` | 季报观点、访谈、争议 | 标注来源与日期 |

**口径红线（改动必须同步 `references/data-pipeline.md` 与 `invest-cli` 代码）**：

- 任职以来基期 = **任职日前一交易日**（任职日即成立日时取成立日）—— 与 Wind「区间收益率」同口径，任职当日收益计入；
- 年度最大回撤取**年内峰值→谷值**口径，不跨年回溯前一年末高点（两种口径实测差 1.4pct）；
- 业绩基准指数 = **基金代码 + BI.WI**（万得编制的基金业绩比较基准指数）；含港股仓位的指数在港股假期无行情，当日点位沿用前值；
- 年度收益率/回撤**优先取官方字段**，本地复算只做校验；本地与官方偏差 >0.05pct 必须写出来；
- 未任职年份标「未任职」、未成立年份标「未成立」，**不留白、不拿前任经理业绩充数**。

## 二、分析框架（六维，逐层递进）

### 维度一：它是什么（画像）
- 类型与契约：偏股混合 / 灵活配置 / 指数增强…；合同允许的仓位区间
- 规模与变化：最新规模、近一年变化、机构占比
- 业绩比较基准：**基准就是它的考试大纲**，持仓与基准偏离度决定它是「增强」还是「另起炉灶」

### 维度二：业绩复盘（定量，全部来自 tenure 输出）
- 分年度收益率与最大回撤（任职期内完整年度逐年看，不只看累计）
- 任职以来累计/年化，与**基准同期**对比，算超额
- 情景分析：上涨市进攻力、下跌市抗跌力（用分年度数据反推，不猜）
- **关键判断**：业绩来自 beta、风格暴露，还是稳定 alpha？超额是否只集中在某一两年？

### 维度三：风险与回撤
- 最大回撤幅度、发生时段、**修复天数**（比回撤幅度更影响拿得住拿不住）
- 波动率、夏普、卡玛（同类分位，不只看绝对值）
- 持有人体验：月度胜率、赔率、净值创新高频率

### 维度四：组合剖析（定性）
- 资产配置与仓位择时习惯
- 行业集中度与偏好、是否与合同主题一致
- 前十大特征：龙头/黑马、高估成长/低估价值；换手率判断长期持有还是波段
- **风格漂移检查**：近三年风格是否迁移（价值经理开始买 AI 是要点名的信号）

### 维度五：人与平台
- 经理：从业年限（是否跨过完整牛熊）、任职稳定性、能力圈、一句话画像
- 是否一拖多、是否新发产品稀释精力（用 `tenure --manager` 的在管清单核对）
- 平台：投研实力、是否依赖单打独斗、同类策略历史表现

### 维度六：成本与持有体验
- 费率结构：管理费/托管费/申赎费；换手率隐含成本 ≈ 换手率 × 0.15%
- A/C 份额选择：持有期长短决定选哪一档（短期 C、长期 A）

## 三、结论与动作

**结论只能四选一**，先给结论再展开：

| 结论 | 触发条件（示例，按实际情况填） |
|---|---|
| 值得跟随 | 三关全过 + 超额稳定 + 回撤可控 + 经理稳定 |
| 可以观察 | 有亮点但有明确疑点（规模膨胀、任职短、单一年度贡献过大） |
| 暂不跟随 | 关键一关不过（看不懂策略 / 无稳定超额 / 估值高位） |
| 明确回避 | 风格漂移、经理将离任、规模过载且策略容量受限 |

**必须包含三件容易被省略的东西**：

1. **横向对标**：至少 2 只同风格基金同期对比，否则「单人简历式结论」不成立；
2. **退出条件**：出现什么信号就不再跟（经理变更、连续两期同类后 50%、规模暴涨后超额消失、费率上调）；
3. **跟踪清单**：下次复查看哪三个指标、什么时间点复查。

## 五、防幻觉约束（写作时自查）

- 数字是否全部来自命令输出？有没有一个是「印象中」的？
- 有没有把 beta 当 alpha？牛市普涨年份的超额要单独标注
- 有没有把「短期排名」写成「能力」？同类分位要看多周期
- 缺失数据是否明确写成「数据不足」，而不是含糊过去？
- 结论是否回答了「下一步动作」，而不只是「好不好」？

## 六、一页速用（复制这段去提问）

```text
调研基金：[代码 + 名称]，经理：[姓名]。
先跑 invest-cli tenure <代码> --manager <姓名> --excel 归档.xlsx 拿业绩/回撤/基准对比，
再跑 invest-cli fund <代码> 拿费率/重仓/同类分位。
按「画像 → 业绩 → 风险 → 组合 → 人与平台 → 成本体验」六维分析，
数字全部标注来源，缺失的写「数据不足」。
最后给四选一结论（值得跟随/可以观察/暂不跟随/明确回避）+ 横向对标 2 只 + 退出条件。
口径：任职以来基期取任职日前一交易日；年度回撤取年内峰值口径；基准为基金代码+BI.WI。
```
