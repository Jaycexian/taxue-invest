# 场景 H：ETF 深度分析

> 触发：「ETF 深度分析」「ETF 穿透」「持仓分析」「ETF 风险分析」「ETF 回撤」「ETF 相关性」

---

## 适用场景

用户需要超越三关审查的 ETF 深度分析：
- 持仓穿透（集中度、行业分布、加权估值）
- 风险增强（信息比率、索提诺比率、下行波动）
- 回撤深度（最大回撤、恢复天数、回撤历史）
- 相关性分析（多 ETF 组合分散化价值）
- 排名动态（同类分位变化趋势）
- 估值分析（PE/PB/PS 及历史分位，来自 Index Hub）
- 资金流分析（净流入趋势，来自 Index Hub）
- ETFirst 增强（估值分位、风险收益比、行业分布、Wind 排名，来自首趋E指）

与场景 E（ETF 分析）的区别：场景 E 走通用三关，场景 H 走深度分析。

---

## 执行步骤

### 第一步：取数

```bash
invest-cli fund <代码/名称> --json
```

如果用户要求相关性分析，额外取多标的 K 线：
```bash
invest-cli kline <代码1> --period day --limit 250 --json
invest-cli kline <代码2> --period day --limit 250 --json
```

### 第二步：调用分析模块

```bash
invest-cli fund <代码/名称> --analytics
```

分析模块自动完成：
1. 持仓穿透（从 fund 数据的 holdings 计算）
2. 风险增强（从 fund 数据的 risk/returns 计算）
3. 回撤深度（从 kline 数据计算，自动获取近 250 个交易日）
4. 排名动态（从 fund 数据的同类分位计算）

## 数据依赖

| 数据 | 来源 | 必需 |
|------|------|------|
| 持仓明细 | fund 数据 holdings | 是 |
| 风险指标 | fund 数据 risk / ttskill | 是 |
| K 线数据 | kline 命令 | 回撤分析必需 |
| 同类分位 | fund 数据 data | 排名动态必需 |
| 多标的 K 线 | kline 命令 | 相关性分析必需 |
| 估值数据 | Index Hub etf/detail | 估值分析可选 |
| 资金流数据 | Index Hub etf/etf-scale | 资金流分析可选 |
| ETFirst 详情 | ETFirst etf-detail all | ETFirst 增强可选 |

---

## 注意事项

1. **零第三方依赖**：分析模块只用 Python 标准库，不需要安装任何额外包
2. **数据缺失处理**：hithink 源的 risk 数据可能全为 null，此时风险增强模块返回"数据不足"，属正常行为
3. **K 线自动获取**：--analytics 参数自动获取近 250 个交易日的 K 线数据用于回撤分析
4. **Index Hub 可选**：Index Hub 数据（估值/资金流）失败时静默降级，不影响其他模块
5. **缓存友好**：fund 数据和 kline 数据都有磁盘缓存，重复查询不会重复取数
