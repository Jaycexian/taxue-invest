# 适配层：通用

> 通用适配：任何金融文档的兜底。自动识别文档类型，均衡提取 5 层信息。

---

## 文档特征

| 特征 | 说明 |
|------|------|
| 作者 | 任何机构/个人 |
| 目的 | 任何金融相关文档 |
| 结构 | 不固定 |
| 篇幅 | 不固定 |
| 核心 | 均衡提取 5 层信息 |

---

## 5 层提取权重

| 层 | 权重 | 说明 |
|---|------|------|
| 论点 | ⭐⭐⭐ | 均衡 |
| 数据 | ⭐⭐⭐ | 均衡 |
| 估值 | ⭐⭐⭐ | 均衡 |
| 风险 | ⭐⭐⭐ | 均衡 |
| 前瞻 | ⭐⭐⭐ | 均衡 |

---

## 文档类型自动识别

当用户未指定文档类型时，按以下规则自动识别：

| 特征 | 识别为 | 适配层 |
|------|--------|--------|
| 含「买入/增持/持有/减持/卖出」+ 目标价 | 研报 | `_adapter-research.md` |
| 含「年度报告」「年报」+ 5 年数据 | 年报 | `_adapter-annual.md` |
| 含「季度报告」「季报」+ 环比数据 | 季报 | `_adapter-quarterly.md` |
| 含「招股说明书」「IPO」+ 募资用途 | 招股书 | `_adapter-prospectus.md` |
| 含「募集说明书」「债券」+ 募资用途 | 债券募集书 | `_adapter-prospectus.md` |
| 其他 | 通用 | 本文件 |

---

## 提取位置

| 层 | 提取位置 | 关键词 |
|---|---------|--------|
| 论点 | 首段/摘要/核心观点 | 「核心」「观点」「判断」「认为」 |
| 数据 | 数据表/财务数据/行业数据 | 「营收」「净利」「毛利率」「ROE」「PE」「PB」 |
| 估值 | 估值/目标价/评级 | 「估值」「目标价」「评级」「PE」「PB」 |
| 风险 | 风险/不确定性/负面信息 | 「风险」「不确定性」「注意」「挑战」 |
| 前瞻 | 未来/规划/展望 | 「未来」「规划」「预计」「目标」 |

---

## 特殊规则

### 规则 1：自动识别文档类型

按上述识别规则自动选择适配层，无需用户指定。

### 规则 2：缺失层标注「未提及」

如果某层信息在文档中不存在，标注「未提及」，不编造。

### 规则 3：数据缺失标注「未披露」

如果数据缺失，标注「未披露」，不编造。

### 规则 4：交叉验证必做

即使文档类型未知，交叉验证必做：
- 数据与结论方向一致
- 数据与估值匹配
- 风险与结论匹配
