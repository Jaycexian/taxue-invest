# 适配层：券商研报

> 研报适配：论点优先，估值+评级必抽，催化剂必抽。

---

## 文档特征

| 特征 | 说明 |
|------|------|
| 作者 | 券商分析师 |
| 目的 | 给出投资建议（买入/增持/持有/减持/卖出） |
| 结构 | 摘要→投资要点→业绩→业务→行业→财务→估值→风险→催化剂→目标价→评级 |
| 篇幅 | 30-100 页 |
| 核心 | 论点 + 估值 + 评级 |

## 特殊规则

### 规则 1：评级 + 目标价必抽

研报的核心输出是评级和目标价，必须抽取：
- 评级：买入/增持/持有/减持/卖出
- 目标价：__ 元（+__%）
- 评级理由：1-2 句（估值偏差% + 业绩预期）

### 规则 2：催化剂必抽

研报通常有催化剂段落，必须抽取 1-3 个：
- 新车型发布/订单/产能投产/政策利好
- 每个催化剂必须具体（时间 + 事件 + 预期影响）

### 规则 3：行业对比必做

研报通常有行业数据对比，必须抽取：
- 行业规模 + 增速
- 公司份额 + 变化趋势
- 行业 PE/PB vs 公司 PE/PB

### 规则 4：业绩预测必抽

研报通常有盈利预测，必须抽取：
- 未来 1-2 年营收/净利预测
- 预测 PE/PB
- 预测依据（如有）
